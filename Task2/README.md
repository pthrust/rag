# База знаний для RAG-бота (вымышленный мир)

Данная база знаний создана на основе вселенной Star Wars с полной заменой ключевых терминов. Содержит 35 документов в формате Markdown и словарь замен terms_map.json.

## Структура

- knowledge_base/ — сгенерированные документы
- terms_map.json — таблица соответствия оригинал → вымышленное название

# Генерация базы знаний

Скрипт для генерации базы знаний был создан с использованием Deepseek

```bash
python generate_knowledge_base.py
```
